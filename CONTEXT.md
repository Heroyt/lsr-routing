## Commit convention

Use the `gitmoji-commits` workspace skill for normal agent-authored commits and release tags.

```text
:emoji: [optional-context] imperative message

optional explanatory details
```

Use one Gitmoji shortcode per commit and split commits by intention. Use `:bookmark:` for release/version commits and tags. Context is optional. Keep the complete subject line at 72 characters or fewer when practical.
